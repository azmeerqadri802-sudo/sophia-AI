# Sophia v2.0 - Autonomous AI Lead Gen CRM (Omnix Global)

Full-stack production codebase featuring a Next.js + Tailwind CSS Dark Obsidian/Brushed Gold/Cyan Neon Glassmorphic UI, Node.js + Express REST API, and MongoDB (Mongoose) schemas with AES-256 encrypted AI API key storage.

## Quick Start

### 1. Start Backend Server
cd backend
npm install
npm run dev

### 2. Start Frontend Application
cd frontend
npm install
npm run dev
